ABOUT THE PROJECT

Designed around people.

SanketSetu is a student community-service project exploring accessible communication and ISL learning.

OUR INTENT

Build access, not assumptions.

Sign languages are complete natural languages, not word-for-word gesture codes. This student project aims to offer a learning entry point and a prototype recognition workflow. It should be reviewed with Deaf and hard-of-hearing community members before any real-world reliance.

02Prototype camera-based ISL word recognition.
